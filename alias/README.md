# voyagier

The official Voyagier CLI. Book real travel from your terminal: search flights, hotels and activities, plan trips, and check out with a price-gated booking. Built for AI agents and travel advisors.

```bash
npx voyagier --help
# or
npm install -g voyagier
voyagier --help
```

This package is the short name for [`@voyagier/cli`](https://www.npmjs.com/package/@voyagier/cli). Both packages ship together at the same version number, and `voyagier@X.Y.Z` installs `@voyagier/cli` X.Y.Z or a later release of the same major version. Documentation and release notes live with `@voyagier/cli`.

To pin an exact CLI version, install the scoped package:

```bash
npm install -g @voyagier/cli@<version>
```
